# 第一版架构

## 系统边界

系统服务于个人投资者的研究、风险监控和模拟交易，不提供真实交易，不承诺收益，也不输出确定性的涨跌预测。

## 核心数据流

```text
公告 / 财报 / 新闻线索 / 日线行情
                |
                v
         数据采集与标准化
                |
                v
       PostgreSQL + 文档向量库
                |
                v
         定时任务与规则引擎
                |
                v
     LangGraph 研究与核验工作流
                |
                v
          待确认模拟建议
                |
                v
             用户确认
                |
                v
     确定性模拟交易引擎与复盘
```

## 模块职责

- `api`：提供 HTTP 接口，不直接实现业务规则。
- `watchlists`：管理自选股分组及成员。
- `market_data`：通过可替换适配器读取日线行情。
- `disclosures`：导入公告、财报及其来源信息。
- `risk`：运行确定性风险规则并生成研究线索。
- `research`：检索、计算、核验并生成带引用的研究报告。
- `paper_trading`：在用户确认后执行模拟交易和金额计算。
- `audit`：保存工具调用、建议、确认和模拟成交轨迹。

## 权限边界

Agent 只生成待确认建议。只有确认接口可以调用模拟交易引擎；模型工具不暴露真实交易能力，也不能直接修改账户余额或持仓。
