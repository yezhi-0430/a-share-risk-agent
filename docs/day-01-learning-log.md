# 第 1 天学习记录

## 1. 这个项目要解决什么问题？
管理多只自选股、持续监控公告和财务风险、生成带来源的研究报告，并在用户确认后进行模拟交易。
## 2. 为什么暂时不接入真实交易？
模型可能出错，数据源可能不稳定，真实交易涉及资金风险和权限安全，所以当前只做研究和人工确认后的模拟交易。
## 3. app/main.py 的作用是什么？
FastAPI 应用入口
## 4. 访问 /health 后发生了什么？
浏览器发送 GET /health
→ Uvicorn接收请求
→ FastAPI匹配/health路由
→ 执行health函数
→ 将Python字典转换为JSON
→ 返回200和{"status":"ok"}
## 5. tests/test_health.py 的作用是什么？
如何自动检查接口
## 6. 为什么 .env 不能上传到 GitHub？
它通常保存 API Key、数据库密码等敏感配置，上传后可能泄露密钥
## 7. Git、GitHub、commit 和 push 分别是什么？
电脑上的版本管理工具。
GitHub：保存和展示远程代码仓库的网站。
commit：在本地保存一次代码版本。
push：把本地提交上传到 GitHub。

目前还不清楚 FastAPI 路由代码的具体语法，以及测试文件如何模拟浏览器请求。
