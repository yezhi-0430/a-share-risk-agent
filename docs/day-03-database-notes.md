## 3. 第一次连接与查询

连接命令：

```powershell
psql -U postgres -h localhost -p 5432 -d postgres
```

参数含义：

- `-U postgres`：使用 `postgres` 角色登录。
- `-h localhost`：连接本机数据库服务器。
- `-p 5432`：连接 PostgreSQL 默认端口。
- `-d postgres`：连接名为 `postgres` 的数据库。

第一条 SQL：

```sql
SELECT current_user, current_database();
```

查询结果证明当前角色和数据库都是 `postgres`。

SQL 通常以英文分号 `;` 结束。`postgres=#` 表示可以输入新命令，`postgres-#` 表示上一条命令尚未结束。可以按 `Ctrl+C` 取消尚未结束的输入。

`psql` 中以反斜杠开头的命令是客户端命令，例如：

```text
\q
\password postgres
```

它们不是 SQL，不需要分号。

## 4. 为什么项目不能直接使用 postgres

`postgres` 是数据库超级管理员，权限过大。Web 应用如果使用超级管理员账户，一旦配置泄露或代码出现漏洞，攻击者可能修改整个数据库服务器。

本项目将创建：

- 项目角色：`a_share_agent`。
- 项目数据库：`a_share_risk_agent`。

应用只使用项目角色连接项目数据库。这体现了最小权限原则：程序只获得完成工作所需的权限。

## 5. 三张核心表

```text
watchlists
    id (主键)
    name

stocks
    id (主键)
    symbol (唯一)
    name

watchlist_items
    id (主键)
    watchlist_id (外键 -> watchlists.id)
    stock_id (外键 -> stocks.id)
    (watchlist_id, stock_id) 唯一
```

`watchlist_items` 是关联表，用来表达“一个分组中有哪些股票”。组合唯一约束负责阻止同一只股票重复加入同一个分组。

## 6. 今天要理解的数据库概念

### 主键

主键唯一标识表中的一行。例如两个分组可以名称相同，但它们的 `id` 不同。

### 外键

外键建立表之间的关系，并阻止关联到不存在的数据。例如 `watchlist_items.watchlist_id` 必须指向一个真实存在的分组。

### 唯一约束

唯一约束由数据库保证某个值或值的组合不会重复。本项目使用 `(watchlist_id, stock_id)` 组合唯一约束防止重复添加。

### 索引

索引帮助数据库更快地定位数据，但也会占用空间，并增加写入成本。唯一约束通常会创建相应的唯一索引。

### 事务

事务把多项数据库操作视为一个整体：要么全部成功，要么全部撤销。例如添加一只新股票并把它加入分组时，不应只完成其中一半。
