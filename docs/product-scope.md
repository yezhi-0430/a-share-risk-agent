# 产品范围

## 目标用户

希望持续跟踪多只 A 股、但没有时间逐份阅读公告和财报的个人投资者。

## 用户故事

1. 作为个人投资者，我希望按主题维护多组自选股，以便集中跟踪自己关心的公司。
2. 作为个人投资者，我希望系统每天扫描公告和日线异常，以便及时发现需要进一步研究的风险线索。
3. 作为个人投资者，我希望每条 AI 结论都能返回原始来源、日期和页码，以便自行核验。
4. 作为个人投资者，我希望比较公司的财务指标和风险变化，但不希望模型代替程序计算金额。
5. 作为个人投资者，我希望 Agent 给出模拟操作建议后由我决定是否执行，以便保留最终控制权。
6. 作为个人投资者，我希望查看当时的证据、决定和后续结果，以便复盘研究过程而不只看盈亏。

## 八周首版包含

- 多自选股分组及日线数据导入。
- 公告、财报和价格成交量风险线索。
- 带来源和页码引用的公司研究。
- 可追踪、可恢复的研究工作流。
- 用户确认后的模拟交易。
- 持仓、收益、研究快照和复盘。
- 自动测试、评估集、审计日志和 Docker 启动。

## 八周首版不包含

- 真实券商账户、QMT 或自动下单。
- 收益承诺和确定性涨跌预测。
- 分钟级行情、高频交易和复杂策略回测。
- 模型训练、微调和多 Agent 集群。
- 付费、社交、多人协作和复杂权限系统。

## 成功标准

- 用户能够从新增自选股开始，完成扫描、研究、建议确认、模拟成交和复盘的完整流程。
- 每项重要风险结论都有可核验来源，资料不足时系统明确拒答。
- Agent 无法跳过人工确认或直接修改模拟账户。
- 固定评估集能够衡量风险识别、检索命中、引用正确和数字正确率。
- 陌生开发者可以按照 README 在本地启动并运行测试。
